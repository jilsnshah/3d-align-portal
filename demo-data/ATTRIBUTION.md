# Demo data

Clinical photographs and radiographs used to make the demo look like a real
case list. Every image is openly licensed and was published for educational
use — none of it is patient data belonging to 3D Align or any clinic.

The `.stl` files in `scans/` are generated placeholders, not real scans. A
genuine intraoral scan is tens of megabytes and shows nothing useful on a
screen share.

No extraoral (face) photographs are included. Those slots are optional in the
portal, and using a real person's face as a fictional patient is a line worth
not crossing for a demo.
